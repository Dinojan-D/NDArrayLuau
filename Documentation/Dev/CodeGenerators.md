# Kernel Code Generator (CG) - Developer Guide

_Generated by Gemini_

This pipeline provides a data-driven, template-based code generator that produces specialized, zero-overhead monomorphic Luau kernels for the NDarray library.

## Directory Structure

- `renderer.py`: Python entry point. Ingests data, triggers template compilation, applies post-processing, and writes output files.

- `template.luau.j2`: Master kernel skeleton defining imports, variables, and structural layout.

- `components/`: Directory containing specialized .luau.j2 macro files (e.g., scalar operators, fill strategies, buffer-to-buffer engines).

- `.config.json`: Strategy map binding each dtype (e.g., i8, f32) to specific macro method names.

- `context.json`: Static mapping defining dtype classifications and operator symbol dictionaries.

## Generation Workflow

- Context Resolution: renderer.py loads .config.json and context.json to extract dtype attributes (bit/byte sizes, value categories).

- Dynamic Rendering: Jinja2 compiles template.luau.j2. Strategy names defined in .config.json dynamically invoke corresponding macro functions inside components/.

- Regex Clean-Up: Python cleans the rendered code by enforcing mandatory directives (--!strict, --!optimize 2), stripping trailing spaces, and collapsing excess line breaks (\n{3,} $\rightarrow$ \n\n).

- File Output: Saves the generated code directly to src/shared/NDarray/kernels/{dtype}.kernel.luau.

## IDE Setup Recommendation

Install a Jinja2 Extension in your code editor (e.g., Jinja or Better Jinja in VS Code). Configure .j2 or .luau.j2 file extensions to render with Jinja/Lua formatting to enable syntax highlighting and maintain template readability.
